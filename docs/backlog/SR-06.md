# SR-06: Build reviewed clause and parcel reference corpus

Status: Blocked (planning status, not implementation progress)
Milestone: M1: Technical proof
Dependencies: SR-05

## Outcome

Create explicit expected interpretations and outcomes against which extraction and evaluation can be tested.

## Scope

Build about three real, manually reviewed design/site/placement packets plus approximately 20–30 source clauses as justified by actual complexity. Keep synthetic boundary tests separate from real-site evidence.

## Acceptance criteria

- [ ] Each clause includes exact evidence, relevant definitions/cross-references, expected interpretation, reviewer status, and rationale.
- [ ] Cover simple limits, conditions, exceptions, ratios, alternative pathways, and unsupported cases; record reviewer disagreement.
- [ ] Separate prompt-development and held-out examples before tuning.
- [ ] Include defensible candidate, exclusion, and investigation scenarios where available; distinguish synthetic cases from real cases.
- [ ] Reference outcome scope and source dates are explicit; a completed development is not treated as current zoning ground truth.

- [ ] Include wrong-era rule selection, invented source fields, interior-versus-regulatory area, roof-specific height, wrong ratio denominator, unsupported coverage, and failed-placement overgeneralization as regression categories.
- [ ] Do not manufacture a positive real-site result. Existing permits are historical/pathway evidence, not current fit ground truth for this model.
- [ ] Each site packet identifies principal building, lot-line classification, rear yard, supplied placement, and missing facts. Expected checks must be independently justified; provisional annotations remain labelled provisional.
- [ ] Hold out groups of related provisions/definitions together where necessary to avoid leakage from prompt tuning.

## Out of scope

No claim that provisional annotations or provider agreement establish legal correctness.

## Verification evidence

Versioned corpus manifest, annotations, and reviewer notes.

## Open decisions and constraints

An unbiased customer sample is reserved for SR-16; this deliberately selected test corpus cannot estimate population accuracy.
