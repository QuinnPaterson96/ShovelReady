# SR-14: Provision a minimal protected demo environment

Status: Blocked - complete local source-to-result demo and project/budget configuration required (wave 2 integration: 2026-09-24)
Milestone: M2: User-tested MVP
Dependencies: SR-13

## Outcome

Provide a shareable pilot deployment with persistent data and a known operating cost.

## Scope

Choose a simple ShovelReady-owned host, managed PostgreSQL, and durable source storage; record a cost/access decision before provisioning.

## Acceptance criteria

- [ ] One environment runs the image with HTTPS, protected pilot access, private database access, and managed secrets.
- [ ] Document provider, expected monthly cost, budget alerts/limits available, and project-specific ownership; no Styx identities/resources.
- [ ] Data persists across application replacement; configure backup retention and successfully restore a sample backup into an isolated target.
- [ ] Ingestion/review remains an authenticated operator workflow; logs exclude credentials and unnecessary customer identifiers.
- [ ] Document health/failure inspection and teardown; distinguish provider availability from actual recovery tests.

## Out of scope

No independent production environment, Kubernetes, microservices, or enterprise identity system.

## Verification evidence

Deployment URL/access instructions, restore evidence, cost record, and runbook.

## Open decisions and constraints

Requires configured personal project credentials and owner-selected spending limit; draft artifacts can precede provisioning.
