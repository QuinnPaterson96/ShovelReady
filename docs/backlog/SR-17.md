# SR-17: Measure transfer cost in a second municipality

Status: Deferred (planning status, not implementation progress)
Milestone: M3: Expansion experiment
Dependencies: SR-16

## Outcome

Test regional flexibility after the first workflow demonstrates value.

## Scope

Choose a second city in the pilot user's actual territory and reuse the same design/workflow where appropriate.

## Acceptance criteria

- [ ] Record acquisition, interpretation, extraction, review, implementation, and update effort separately.
- [ ] Document which contracts/checks transfer unchanged and which genuinely require local logic.
- [ ] Replay a verified amendment, identify affected rules/results, and measure correction effort while preserving historical releases.
- [ ] Compare added customer usefulness with marginal maintenance cost; recommend expansion or narrower scope.

## Out of scope

No national rollout or generic jurisdiction plugin framework in anticipation of differences.

## Verification evidence

Transfer-cost report and small cross-municipality regression corpus.

## Open decisions and constraints

Activate only if pilot evidence supports further investment; second geography is not first-MVP scope.
