# SR-10: Evaluate a bounded set of coherent development checks

Status: Ready for bounded core task F3; accepted real-site evaluation remains blocked (wave 2 integration: 2026-09-24)
Milestone: M1: Technical proof
Dependencies: SR-06, SR-08, SR-09

## Outcome

Produce explainable preliminary screening from supported reviewed semantics.

## Scope

Implement approximately 5–8 evidence-supported checks for a fixed design at a supplied reviewed placement, as ordinary deterministic Python modules. Separate zone eligibility, site-independent design checks and placement-specific checks.

## Acceptance criteria

- [ ] Each check identifies applicable rule revision, facts, measurement basis, assumptions, outcome, and evidence.
- [ ] Equivalent units give equivalent results; percentage 45% normalizes to 0.45 while FSR 1.2 remains 1.2.
- [ ] Unknown conditions never become numeric zero, unlimited permission, a verified pass, or an unsupported prohibition.
- [ ] Pathway aggregation never combines incompatible optimistic bounds; scoped exclusion has decisive evidence across evaluated alternatives and unresolved alternatives remain visible.
- [ ] Setback/height/floor-area calculations run only with supported definitions and required inputs; approval status remains distinct.

- [ ] A failed placement cannot produce a universal no-fit conclusion without an independently sufficient constraint. Outside coverage is not an exclusion; absent required site facts yields investigation.
- [ ] Check current rule applicability and definitions, including roof-specific height measurement, average-grade inputs, floor-area inclusions and rear-yard occupancy basis.
- [ ] Do not copy plus-site restrictions, automatic heritage/secondary-suite exclusions, or numerical limits from research summaries without accepted source evidence.
- [ ] Document unassessed general/zone rules and cross-references; the garden-suite section alone is not assumed to establish complete coverage.

## Out of scope

No geometry placement optimizer, universal rule solver, financial feasibility, or permit entitlement.

## Verification evidence

Reference-corpus regression tests including thresholds, incompatible alternatives, and uncertainty propagation.

## Open decisions and constraints

Supported check selection follows actual available evidence, not a fixed list of attractive UI fields.
