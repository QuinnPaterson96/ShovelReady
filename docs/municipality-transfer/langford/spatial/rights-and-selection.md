# SR-47: candidate selection and municipal rights

Reviewed 2026-09-26 for issue #103. This is an offline, unreviewed observation packet. No Langford municipal feature response was captured or retained in this follow-up.

## Replaying a saved choice

Run `python -m uv run --locked python tools/municipality_transfer/langford_spatial.py` to list each candidate's `locator`. The default for all three addresses remains `ambiguous`. To examine a candidate, run the same command with `--select lone-oak=LOCATOR` (or `jenkins` / `glen-lake`), copying the exact locator from the output. Multiple `--select` flags may be supplied. The locator combines the candidate's zero-based position with a digest of its saved feature; the result records the geocoder URL, capture time, SHA-256 and replay revision. A locator from another capture or a changed feature is rejected. Selection is an analyst choice for replay, not evidence that an address or PID belongs to the selected point.

The saved geocoder responses each have three results and `maxResults=3`: further candidates may exist. Lone Oak's selected first result is `CIVIC_NUMBER` precision, while Jenkins and Glen Lake first results are `BLOCK`; these are provider categories, not metre accuracy guarantees. The requested and returned address strings are both emitted, with a text-equality flag. Alternate candidates include different streets or municipalities, so selecting them must not silently equate their address to the lead. All points and geocoder requests are EPSG:4326. PMBC geometries are EPSG:3005. Replay transforms the point to polygon CRS only for containment.

Each saved PMBC WFS bbox is a 0.00001-degree half-width query around the **first** geocoder point. `numberMatched=numberReturned` for those exact queries (2/2, 1/1, 3/3), below the URL's `count=20`; this checks completeness for those saved bboxes only. Selecting the first point reproduces a spatial candidate for Lone Oak and no containing polygon for Jenkins/Glen Lake. Every other saved candidate falls outside its case's bbox, so replay reports `unavailable` for parcel coverage rather than treating a missing polygon as a negative finding. Each point needs its own licensed bounded query before a parcel test can be repeated. PMBC is a graphical parcel view, not a legal survey or an address-to-PID crosswalk. Temporal differences, strata, geocoder placement and source geometry remain unresolved. A unique containing PID is still `parcel_match_verified=false`.

## Published rights and attribution by dataset

The City's [mapping page](https://langford.ca/city-hall/mapping/) links public viewing. Its [disclaimer](https://langford.ca/disclaimer/) permits unaltered copying for general use and information but says retransmission, distribution and commercial use require written permission. The [privacy policy](https://langford.ca/city-hall/privacy-policy/) also cautions against commercial copying of copyrighted material without express written permission. Blank `Copyright Text` in the ArcGIS metadata is not a grant. Applicability of website terms to each ArcGIS endpoint, third-party components, derivative geometry, caching and required attribution need the City's written answer. This is a conservative rights decision, not legal advice.
