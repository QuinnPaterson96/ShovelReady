Status: Tooling and actual paired-control evidence integrated; independent human calibration remains open (September 24, 2026)

## Outcome

Turn recorded behavior into an evidence-backed findings ledger, useful measurements
and reproducible issue drafts while preventing agent guesses from flooding the backlog.

## Acceptance criteria

- [x] Accept SR-27 cases/runs and a separately supplied frozen rubric. Grade individual
  claims/checks with evidence: supported, partial, unsupported, not attempted or
  unassessable. Preserve initial judgments and later adjudications as distinct revisions.
  Invalid evidence or a broken test environment cannot yield a successful application
  outcome or a fabricated failure of legal interpretation.
- [x] Use deterministic checks for exact identities/values where justified and explicit
  reviewer decisions for semantic judgments. Define an optional model-review input/
  output protocol using saved responses; no live service dependency is required.
  Models may suggest findings but cannot establish legal truth or approve their own
  unsupported judgments. Attribute reviewer role and actual human involvement honestly.
- [ ] Evaluate the grader on a small hand-reviewed answer set containing a correctly
  supported report, critical omission, invented bug, legitimate unknown, disputed
  interpretation and environment failure. Record grader/reviewer disagreements and
  remaining calibration limits; agreement between models alone is insufficient.
- [x] Classify app defects, agent errors/omissions, false alarms, source/data gaps,
  environment/tool failures and human-usability hypotheses separately. Repeated agent
  omissions can motivate investigation but do not prove UI causation. Correctly stating
  uncertainty must not be penalized as task failure when evidence is insufficient.
- [x] Report raw counts with denominators by task/detection mode, category and severity:
  task checklist outcomes, critical omissions, unsupported conclusions, confirmed finding
  precision, seeded-fault detection, clean-control false alarms and review effort.
  Unknown-defect recall is unmeasurable. Zero/unknown denominators yield N/A, not 100%.
  Show blocked/unassessable attempts and do not pool modes into a misleading overall score.
- [x] Generate local issue drafts only for adjudicated actionable findings, with run/case/
  app/data identity, observed versus expected evidence, reproducible steps, severity,
  proposed acceptance criteria and suitable regression layer. Keep hypotheses/data gaps
  labelled as such. Deduplicate by stable cause/check references while preserving runs;
  updating an existing issue is preferable to a duplicate. Publishing stays a deliberate
  integration action, not an automatic side effect of evaluating a report.
- [x] Offline tests cover incorrect/missing evidence, false positives, missing denominators,
  changed rubrics, deduplication and unadjudicated findings being withheld from bug drafts.
  Confirm an SR-26-derived sample does not invent an application defect.
