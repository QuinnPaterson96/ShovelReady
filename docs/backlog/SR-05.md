# SR-05: Capture immutable source and design snapshots

Status: Partial - licensed typed intake integrated with storage; full private/design bundle remains blocked (wave 1 integration: 2026-09-24)
Milestone: M1: Technical proof
Dependencies: SR-01, SR-04

## Outcome

Make the actual inputs reproducible independently of changing URLs.

## Scope

Add an explicit local acquisition command and manifest for selected regulations, spatial extracts, and a fixed design; support reviewed manual measurements.

## Acceptance criteria

- [ ] Retain source URL/identifier, bytes or authorized durable artifact, content hash, capture time, original units/CRS, and available version/effective-date evidence.
- [ ] Design measurements identify exact configuration, measurement basis, fixed/adaptable status, and whether supplied or manually verified.
- [x] Repeated capture of identical content is idempotent; changed content creates a new snapshot.
- [x] Record reuse/attribution constraints and unavailable material; fixtures avoid unauthorized redistribution.
- [x] Capture failure leaves prior snapshots usable and emits a diagnostic without secrets.

- [x] Save actual GIS service metadata and feature responses, not report placeholder JSON. Record capture time, dataset/service/layer identity, fields, original CRS, observed data quality, and separately verified reuse terms.
- [ ] Use current official regulations and definitions for the selected sites. Record conflicting historical sources as historical, not as current accepted rules.
- [x] For The Landing, obtain or explicitly mark missing versioned drawings, roof/eave measurements, foundation datum and area accounting. Marketing dimensions do not constitute a verified regulatory measurement.
- [x] Retain independent evidence for update cadence, accuracy and licence; do not infer them from public access or a report's assertion.

## Out of scope

No mandatory IFC conversion/export, DASH API integration, or crawling entire municipalities.

## Verification evidence

One frozen real input bundle, reproducible command, and changed/failed capture tests.

## Open decisions and constraints

If files cannot be obtained, return a concrete missing-input blocker to ticket SR-01.
