# Victoria supply-path research: aux box Model 300 and ORCA Jay

Reviewed 2026-09-25 (America/Vancouver) for [SR-56](https://github.com/QuinnPaterson96/ShovelReady/issues/125), on base `97d4433`. This is a bounded public-source check of supply responsibilities, not a quotation, contract, permit opinion, accepted model configuration or installation confirmation. Reports 15–17 were treated as leads; the [report audit in PR #128](https://github.com/QuinnPaterson96/ShovelReady/pull/128) explains why their broader BC and foundation claims cannot be carried forward. Links below are live pages inspected on the review date; source bytes and contractual versions were not retained.

**Decision.** Both candidates have a *plausible documented route to Victoria*: each manufacturer markets the named model, is based on Vancouver Island, and describes delivery/crane services; aux box expressly offers permit handling on Vancouver Island, while ORCA expressly offers BC project management. Neither public record establishes a completed Victoria installation of the named model, a named Victoria installation partner, or an agreed all-in site scope. Jay's delivery/crane price language conflicts within the current marketing pages. Manufacturer confirmation and a site-specific written scope remain the gate before representing either as supplied and installed for a particular Victoria site.

Evidence labels: **M** = explicit named-model statement; **R** = express regional offer; **G** = general manufacturer process/FAQ claim; **H** = historical project/example, without transfer to this model or region; **C** = unresolved contradiction; **NF** = not found in the bounded sources. A claim of availability is not a promise that a particular route, parcel or permit will work.

## Local examples and stopping point

- **aux box:** A1 carries a Tofino testimonial about “new homes” on its Model 300 page. It gives no model identity, date, contractual roles or verified completion record; label **H**, not a Model 300 Victoria installation. A3 proposes visits to existing clients' units, without identifying a public Model 300 project. No homeowner details were collected.
- **ORCA:** O3's home page says “100+ homes delivered across BC” and includes a Quail homeowner testimonial; neither is a Jay installation record. The old [Jay portfolio page](https://www.orcalgs.ca/portfolio/jay/) labels Jay as a product and calls for a quote, not a documented finished project. Its older CAD $197,000 price differs from O1's CAD $207,000 and cannot be treated as the current price. No publicly identified completed Jay project or named installer for Victoria/Vancouver Island was found in the bounded official sources.
- **No ferry evidence:** Neither manufacturer's inspected pages assigns ferry logistics or charges. Their Island location reduces no documented cost to zero. No additional partner/project source was directly named for these models, so public research stops here.

Under BC project management, who is the permit applicant and which named local trades execute site work? Please identify the current Jay permit-document set, any Victoria-area installation partner, and the structure versus site-work warranty terms. No site address or quote is requested at this stage.
