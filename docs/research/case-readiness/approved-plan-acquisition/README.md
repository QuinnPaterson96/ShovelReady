unquoted. Guidance describes City Hall viewing two business days after payment;
the request page allows up to three weeks for copying. These are published service
descriptions, not bookings or guaranteed delivery dates. Electronic delivery remains
to be confirmed.

The [City disclaimer](https://www.victoria.ca/legal-disclaimer) (AP-RIGHTS) restricts
reuse/distribution/commercialization without written permission and describes web
copies as informational. Access or owner consent does not establish designer
copyright permission. No reviewed grant covers durable source storage, team sharing,
machine processing, derived measurements or publication. Drafts ask for these terms
and any retention/deletion conditions; none are invented. Only metadata and original
short summaries are committed, with no third-party bytes or incidental personal data.

The City's [records guidance](https://www.victoria.ca/city-government/freedom-information)

specific route here; an FOI filing is not prepared as a substitute for owner consent.
Published plan-search questions go to **permits@victoria.ca**. Submission, account
creation, owner authorization and any expenditure require a separate user action;
this task's deliverable is the unsent text, not a permission request to continue.

permitted, issuing authority, permit number, sheet identifier, revision/issue and

later footprints, wall faces/projections and boundary labels only within controlled
