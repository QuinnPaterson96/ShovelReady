# Source and access matrix

All sources below were checked or attempted **2026-10-16 UTC**. Dates in the freshness column describe the source, not a warranty of currency. **D** = primary documentation/content read; **T** = successful read-only data response inspected; **I** = product inference; **U** = unknown, unresolved or access failed. Documentation access is not authenticated data access. Search results were leads only; unverified snippets are not adopted numerical inputs.

Only two manufacturer options, one cost-guide comparator, three rental source families and three listing routes are shortlisted. Municipal/regional rows provide the necessary authority detail, not a vendor directory. Publicly readable HTML/PDF is not a licensed API. Unless explicitly stated otherwise, no redistribution licence or maintained public API was established; link and review manually rather than republish source assets or automate collection.

### Questions that must precede any listing integration

The product owner should specify the proposed use on paper before a future access enquiry: a homeowner checking their own lot, an agent displaying listings, or a buyer ranking acquisition opportunities. Request an explicit answer for each of internal analysis, derived suitability scores, joining external parcel/rule data, user exports, paid access, saved reports after delisting, backups, media storage and deletion, attribution, geographic/field completeness, sold/comparable access and termination. Clarify whether a small independent SaaS may contract directly as a Partner/advertising site, must serve a member-controlled site, or is ineligible for this use. These are **unsent questions**, not evidence of permission or a plan to procure data.
